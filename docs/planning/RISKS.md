## Trust Boundaries (Phase-14)
| Boundary | What crosses | Validation / control | What can go wrong | Mitigation |
|---|---|---|---|---|
| UI ↔ Sidecar (localhost IPC) | commands, gate decisions, edits; SSE events | schema-validate every command; sidecar = **sole writer**; localhost-only bind | malformed/forged commands; UI desync | versioned contract; idempotent commands; reconnect+replay |
| Sidecar ↔ Cloud providers | prompts, images, job ids, artifacts, **API keys** | keys from keychain; validate/limit responses; **never trust output unvalidated**; cost/rate handling | key leak; bad/huge output; cost blowup; outage | redact keys; response validation; retry/backoff; soft-budget |
| Sidecar ↔ LangSmith | traces, metadata, artifact **refs** | **fail-open**; no secrets/PII; refs not binaries | data egress; offline stall | fail-open; redaction; swap to local backend |
| Sidecar ↔ Blender/@s4tk (subprocess) | mesh/params/donor/GEOM/tuning | validate in/out; timeouts; **deterministic validation before state writes** (MCP-003/ORCH-004) | crash/hang; bad GEOM; corrupt package | process-tree kill; round-trip validation gate |
| Export ↔ user's Sims 4 install | read donor `.package`; write Mods folder | read-only donors; **never overwrite without confirm**; path config | wrong donor; clobbered files | confirm prompts; backup; isolated output |
| Secrets store (keychain) | API keys | OS keychain; redaction everywhere | plaintext leak | keychain; secret-scan tests |
